# Уровень B

## Сравнение Logistic Regression с PCA и без PCA

Для оценки влияния PCA использовалась модель `LogisticRegression`.

Сравнивались четыре варианта:

1. без PCA;
2. PCA с сохранением 80% дисперсии;
3. PCA с сохранением 90% дисперсии;
4. PCA с сохранением 95% дисперсии.

Масштабирование и PCA выполнялись внутри `Pipeline`, чтобы избежать утечки данных при кросс-валидации.

### Результаты

| Вариант | Признаков | Качество CV | Качество test | Время обучения |
|---|---:|---:|---:|---:|
| Без PCA | 30 | 0.9780 | **0.9825** | 0.0390 с |
| PCA 80% | 5 | 0.9692 | 0.9561 | 0.0367 с |
| PCA 90% | 7 | 0.9714 | 0.9474 | **0.0185 с** |
| PCA 95% | 10 | **0.9824** | 0.9737 | 0.0292 с |

### Анализ

Лучшее качество на тестовой выборке показала модель без PCA:

```text
0.9825
```

PCA 95% позволил:

- уменьшить количество признаков с 30 до 10;
- сохранить высокое качество — 0.9737;
- уменьшить время обучения с 0.0390 до 0.0292 секунды.

PCA 90% дал самое короткое время обучения:

```text
0.0185 с
```

но качество на тестовой выборке снизилось до:

```text
0.9474
```

### Вывод

PCA не дал выигрыша по максимальному качеству, поскольку лучший результат получен без PCA.

Однако PCA 95% является хорошим компромиссом между:

- количеством признаков;
- качеством модели;
- временем обучения.

Поэтому PCA может быть полезен, если главной задачей является уменьшение размерности признакового пространства.

Поэтому t-SNE в данной работе рассматривается прежде всего как инструмент визуализации.

# Итоговый вывод

В ходе практической работы были изучены PCA, t-SNE и UMAP.

PCA позволяет уменьшать размерность данных, сохранять значительную часть дисперсии и выполнять преобразование новых объектов. На данных клиентов ПР-10 две компоненты сохранили 92.2% дисперсии, поэтому PCA хорошо подошёл для визуализации.

На данных Breast Cancer первые две компоненты сохранили 63.2% дисперсии, а для сохранения 90% информации потребовалось 7 компонент.

В эксперименте с Logistic Regression PCA не улучшил максимальное качество модели. Лучший результат на тестовой выборке был получен без PCA — 0.9825. Однако PCA 95% позволил сократить количество признаков с 30 до 10 при сохранении высокого качества.

t-SNE показал наибольшее значение trustworthiness — 0.9504, а UMAP — 0.9307. Оба метода хорошо подходят для визуального исследования структуры данных.

При этом t-SNE не имеет `transform` для новых объектов, поэтому его использование в обычном обучающем pipeline ограничено. UMAP поддерживает `transform`, а PCA также может использоваться в pipeline.

### Основной вывод

**PCA подходит для уменьшения размерности и построения обучающих pipeline, t-SNE преимущественно подходит для визуализации, а UMAP может использоваться как для визуализации, так и для преобразования новых объектов.**
